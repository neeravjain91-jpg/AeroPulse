# Six-Member Team Plan

| Member | Primary ownership | Key skills |
|---|---|---|
| 1 | AI/ML lead | time-series ML, anomaly detection, evaluation, RUL methodology |
| 2 | Digital Twin / engine modelling | IC-engine basics, thermodynamics, simulation, performance maps |
| 3 | Backend / telemetry | FastAPI, WebSocket/CAN roadmap, data validation, APIs |
| 4 | Frontend / GCS | dashboard UX, charts, operator workflow |
| 5 | Data / validation | dataset audit, signal features, fault tests, metrics, documentation |
| 6 | Embedded / integration / security | CAN/SocketCAN, edge deployment, telemetry integrity, integration |

## Minimum shared knowledge

Everyone should understand:

- RPM, CHT, EGT
- oil pressure / temperature
- fuel flow
- battery / alternator health
- anomaly vs fault vs sensor failure
- Digital Twin expected-vs-observed concept
- why RUL needs degradation/run-to-failure data
