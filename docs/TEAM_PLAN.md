# Six-Member Team Plan

| Member | Ownership | Skills |
|---|---|---|
| 1 | AI/ML | anomaly detection, evaluation, RUL methodology |
| 2 | Digital Twin | IC-engine basics, thermodynamics, simulation |
| 3 | Backend/telemetry | FastAPI, WebSocket, CAN roadmap, APIs |
| 4 | Frontend/GCS | dashboard UX, charts, operator workflow |
| 5 | Data/validation | dataset audit, signal features, metrics, tests |
| 6 | Embedded/integration/security | CAN/SocketCAN, edge deployment, telemetry integrity |

Everyone should understand RPM, CHT, EGT, oil pressure/temperature, fuel flow, battery/alternator health, anomaly vs fault vs sensor failure, expected-vs-observed Digital Twin logic and why RUL needs degradation data.
